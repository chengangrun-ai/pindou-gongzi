常见问题

先问清楚，再动手拼

收费吗？

免费，AGPL 开源，不用注册。图纸上的品牌小标可以一键关掉，不强制留任何水印。

我的图片会上传吗？

不会。网页版在你自己的浏览器里解码和渲染；命令行和接口版在你自己的机器上跑。服务器只托管页面代码，不接收图片。

支持什么图片格式？

PNG、JPEG、BMP。WebP 和 GIF 请先转成 PNG，这是为了保证桌面和网页输出逐像素一致。

色号准吗？

用 Oklab 感知距离取最近的品牌色，不是简单 RGB 比大小。导出前还能排除不想要的颜色，整图自动重新映射。

能批量处理吗？

能。命令行支持整个文件夹批量，坏图跳过并记录；HTTP 接口和 MCP 工具供脚本与 Agent 调用，每批输出清单文件。

和原版 perler-beads 是什么关系？

算法与色号数据来自 Zippland/perler-beads，豆莉塔按 AGPL 同协议开源并保留署名。产品名、界面、水印引擎、打赏模块和批量接口都是原创重做。

水印能改成我自己的吗？

能。文字或 Logo 图片，九宫格位置或整图平铺，透明度、边距、大小都可调。中文品牌名用 Logo 图片方式加。

打赏的钱给谁？

给你正在使用的这个部署的运营者，收款码在配置文件里替换。上游原作者的捐赠入口在其官方站点，与本站无关。
